# 롱야봇 — 디스코드 서버 경제·가상 주식 시뮬레이션 (쇼케이스)

> 이 저장소는 **소개 자료 전용**입니다. 원본 소스·커밋 이력·데이터베이스·설정 값은 포함하지 않습니다.
> 현재 상태: **본 시즌 출시(2026-11-06)** — V3 주식시장이 운영 서버에서 동작 중입니다. 확인한 범위와 아직 관찰 중인 부분은 아래 '상태' 표에 적었습니다.

한국어 디스코드 서버에서 서버코인으로 즐기는 놀이용 경제 봇입니다. 출석·예측 베팅·랭킹 같은 기본 경제 위에,
가상 기업의 실적과 공시로 움직이는 **가상 주식시장**을 얹었습니다. 서버코인은 실제 현금 가치가 없고, 실제 금융상품·결제·현금화와 연결되지 않습니다.

## 무엇이 다른가

- **실적으로 움직이는 주가** — 주가는 무작위가 아니라 가상 기업의 매출·이익·현금흐름·수주 잔고에서 나옵니다. 매주 토요일 14시 실적 발표, 매시 정각 가격 확정.
- **살아 있는 세계** — 지역 분쟁·무역 갈등·팬데믹·원자재 공급 차질·업계 경쟁이 기업 실적에 이어집니다. 사건은 공개 시각이 정해져 있고, 공개 전 정보는 보이지 않습니다.
- **비상장 기업이 상장까지** — 새 기업이 자금을 모아 설립하고, 영업 실적을 쌓아 상장 심사를 받고, 공모(청약 7일 이상)를 거쳐 거래소에 오릅니다.
- **기업 간 거래** — 공급 계약·작품 라이선스·보험·조선 수주 계약이 실제 장부로 기록되고, 연체·해지·청산까지 처리합니다.
- **NPC 투자자** — 서로 다른 성향의 NPC 투자자가 시장에 유동성을 공급합니다.
- **놓친 소식 다시 보기** — 자리를 비운 사이(1시간·1일·3일) 공개된 공시·실적·속보·비상장 기업 소식을 원문과 함께 묶어 보여 줍니다.

## 화면 예시

`previews/` 의 HTML(PC 900px · 모바일 360px 폭)은 실제 화면 함수가 만든 응답을 오프라인으로 그린 **근사 화면**입니다(시험용 데이터 — 실제 Discord 클라이언트 캡처가 아닙니다).
시장 홈·종목 상세(차트·손익계산서·재무상태표·현금흐름표)·주문 확인·체결 영수증·계좌·공모주 청약·기업 실적 목록·경제 뉴스 화면이 있습니다.

## 기술

Python 3.11 · discord.py · SQLite(WAL) · 결정적 시뮬레이션(같은 시드·같은 입력이면 같은 결과, 재시작 뒤 이어서 계산) · 모든 금전 이동은 원장으로 대조.

## 상태

| 영역 | 상태 |
|---|---|
| 기본 경제(출석·예측·랭킹·상점) | 운영 중인 기존 기능 |
| V3 주식시장(정각 가격·NPC·거래소·주문·계좌) | **운영 중** — 출시일 첫 정각 10종목 가격 확정·주가 알림 발송 확인, 오류 0 |
| 비상장 기업·IPO·청약·자동 계약 | **켜짐·관찰 중** — 카탈로그 15곳 사업 개시 예약(출시 다음 날), 첫 설립·상장·청약 사례는 아직 없음 |
| 놓친 소식 다시 보기 | 켜짐 — 실제 화면 전체 확인은 진행 중 |
| 새 시즌 | 지난 시즌 기록은 백업으로 보관, 플레이어 자산·기록은 새로 시작(서버 설정·상점 칭호만 이어짐) |
| RPG·가챠(탐험·강화·월드보스·뽑기) | **폐기** — V3 본 시즌에는 없음(명령·데이터 표 모두 제거, 지난 시즌 기록은 외부 백업에만 보관) |

## 검증 수치(출시 후보 검증 2S — 격리 환경, 운영 배포 전)

| 항목 | 결과 |
|---|---|
| 출시 설정 통합 시뮬레이션 | 3개 시드 × 230일, 실제 런타임(가격·NPC·거래소) |
| 비상장 → 상장 | 자연 상장 34건 — 기업마다 8개 대조(발행 주식·배정·공모 대금·가격·실적·NPC 등) 모두 통과 |
| 플레이어 공모 청약 | 34건 모두 입고, 같은 요청을 다시 보내도 중복 없음 |
| 원장 대조 | 거래소 무결성 문제 0, 플레이어 현금 = 원장 합 |
| 강제 시나리오 | 청약·공모 취소·환불·중단 복구 18건, 금융 부실·인수합병·보험·보증 8건 모두 통과, 팬데믹 큰 파동 14.1일 |
| 1GB 메모리 상한 측정 | 최대 약 101MB, 매시 정각 처리 중앙 262ms, 72시간 멈춘 뒤 따라잡기 11.4초 |
| 자동 시험 | 104개 모듈 2,163개 |

위 수치는 출시 전 격리 환경의 리허설 결과입니다. 운영 서버(1GB)에서는 출시일 첫 정각 처리와 메모리(봇 약 92MB)를 확인했고, 장기 메모리·비상장 기업 첫 상장·실제 Discord PC·모바일 화면 전체는 **관찰 중**입니다.
